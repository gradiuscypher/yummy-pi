# yummy-pi

My [pi.dev](https://pi.dev) setup. The custom extensions that used to live here
were removed in favor of community packages. Candidates are below; none are
installed or vetted yet.

| Replaces | Candidates |
|---|---|
| plan-mode | `@narumitw/pi-plan-mode`, `@devkade/pi-plan`, `pi-plan`, `@plannotator/pi-extension` |
| questionnaire | `@mrclrchtr/supi-ask-user`, `@juicesharp/rpiv-ask-user-question`, `@arhen/pi-core-ask`, `@nguyenquangthai/pi-ask` |
| spend-tracker | `pi-local-stats`, `pi-token-usage-statistics`, `@tmustier/pi-usage-extension`, `@zhcsyncer/pi-meter` |
| tmux-pane | `@ogulcancelik/pi-tmux`, `@getpipher/term` |
| conversation-id | `pi-provider-headers` (partial; may need a small local extension) |
| dev-guide | none needed once there are no local extensions |

Install with `pi install npm:<package>`.
